# ScheduleDefinitionOutput

Output representation of a schedule with required schedule_id.

Used when returning schedules from the API where schedule_id is always present.

## Example Usage

```typescript
import { ScheduleDefinitionOutput } from "@mistralai/mistralai/models/components";

let value: ScheduleDefinitionOutput = {
  input: "<value>",
  scheduleId: "<id>",
  workflowName: "<value>",
  paused: false,
};
```
